## 1. アプリ概要

### コンセプト
旅行・お出かけを「構造化されたデータ」として記録し、地図と写真で振り返るパーソナル旅行データベース。
記録が積み重なるほど、ヒートマップで自分の旅の傾向が浮かび上がる。

### 既存サービスとの差別化
- Google マップ マイマップ・Google Photos：旅行単位でのデータ構造化ができない
- 経県値・たびちず：訪問場所の詳細情報（写真・メモ・同行者など）を持てない
- Notion：地図・ヒートマップによる可視化ができない

**本アプリの価値**：旅行単位で構造化された記録データベースに、地図可視化が組み合わさっている点

## 3. 画面構成

### 3.1 メイン画面（3 カラムレイアウト・トップバーなし）

```
┌──────────────┬──────────────────────────┬──────────────┐
│  旅行一覧    │ [0か所]    [ヒートマップ]│  旅行詳細    │
│  （左 384px）│                          │（右 390px）  │
│              │         地図             │              │
│ ・ソート     │        （中央 1fr）      │ ・写真ビュー │
│ ・期間絞込み │                          │   （矢印切替│
│ ・フィルタ   │                          │     カウンタ）│
│ ・旅行カード │                          │ ・全プロパ   │
│   （サムネ） │                          │   ティ表示   │
│ ・＋追加     │                          │ ・編集 / 削除│
└──╫───────────┴──────────────────────────┴──╫───────────┘
   ↑ resize-handle（左右パネル幅をドラッグ／キーボードで変更可能）
```

- **トップバーなし**：機能ボタンは地図上のオーバーレイで実装
- **ピン数バッジ**：地図左上に「N か所」表示（地図に表示中のピン数）
- **ヒートマップ切替ボタン**：地図右上に配置
- **左右パネル幅**：境界線（4px の resize-handle）をドラッグで変更可能。`tabibako_panel_widths` に永続化。ダブルクリックで初期値リセット。キーボード操作にも対応（Tab フォーカス・矢印 10px・Shift+矢印 50px・Home/End・Enter/Space）
- **最小幅制限**：左 240px / 右 280px / 中央 320px

### 3.2 左パネル：旅行一覧

```
┌─────────────────────────────┐
│ Tabibako    [期間] [↓] [＋] │  ← ツールバー
├─────────────────────────────┤
│ [絞り込み：移動手段]        │
│  [車] [電車] [自転車] ...   │
│ [絞り込み：同行者]          │
│ [絞り込み：タグ]            │
├─────────────────────────────┤
│ ┌─────────────────┬───┐    │
│ │ USJと京都       │📷 │    │  ← 旅行カード
│ │ 2024-11-08〜10  │   │    │     （サムネ：60×60）
│ │ 大阪府・京都府  │   │    │
│ │ [電車][田中さん]│   │    │
│ └─────────────────┴───┘    │
└─────────────────────────────┘
```

**旅行カードの表示内容**：
- 旅行名（タイトル）
- 日程（開始日〜終了日）
- 訪問地域（国内：都道府県、海外：国名）
- タグ（移動手段＝青・同行者＝緑・タグ＝紫、全件横スクロール）
- 1 枚目の写真サムネ（60×60、`object-fit: cover`、`align-self: center`、写真なし時は領域確保せず）
- 選択中は青枠 + 薄青背景でハイライト
- `role="button"` `tabindex="0"` `aria-pressed` でキーボード操作対応（Enter / Space）

**ツールバー**：

| ボタン | 機能 |
|---|---|
| 期間絞り込み | 開始日 / 終了日入力のドロップダウン |
| ソート | 日程新しい順・古い順・旅行名あいうえお順 |
| ＋（新規追加） | 旅行登録モーダルを開く |

**絞り込み 3 セクション**（移動手段・同行者・タグ）：

- 値プールにチップが存在するセクションのみ表示
- チップクリックで active 化
- 同カテゴリ内：**OR** 条件
- カテゴリ間：**AND** 条件
- `tabibako_filter` に永続化、リロード後も保持
- 該当 0 件時は「絞り込み条件に該当する旅行がありません」表示
- カラー：移動手段＝青・同行者＝緑・タグ＝紫
- `aria-pressed` 対応

**期間絞り込み**（ソートボタン左）：

- 開始日 / 終了日の `<input type="date">` + クリアボタン
- 判定：trip 期間と filter 期間が**重なる**旅行のみ表示（`(filterStart === '' || trip.endDate >= filterStart) && (filterEnd === '' || trip.startDate <= filterEnd)`）
- 空欄＝無制限
- `tabibako_period_filter` に永続化
- ソート / 期間絞り込みドロップダウンは排他制御（一方を開くと他方を閉じる）

### 3.3 中央パネル：地図

- **Leaflet 1.9.4 + OpenStreetMap**
- 初期ビュー：中心 `[36.5, 138.0]` / ズーム 5（日本中央）
- ズームコントロール：右下配置（地図左上のピン数バッジとの重なりを回避）

**地図ピン**（Issue #5 の方針）：

| 状態 | 表示 |
|---|---|
| 未選択（フィルター済全旅行） | default 青で全件表示 |
| 選択中の旅行 | selected オレンジ・一回り大きい |
| 選択中以外の他旅行 | dim グレー青 |
| 宿泊所（選択中のみ） | 緑系の `ti-bed` アイコン |
| ヒートマップ ON + 未選択 | 全ピン非表示（俯瞰モード） |
| ヒートマップ ON + 選択中 | selected ピン + 宿泊所のみ表示（Issue #12） |
| モーダル open 中 | 全ピン非表示（draft ピンに集中） |

**ポップアップ**：ピンクリックで「旅行名：場所名」表示

**ピン追加（モーダル内）**：

- **住所検索**：Nominatim `/search` API + 500ms debounce + 1 req/sec throttle
- **地図クリック**：「地図から選ぶ」ボタンでピックモードに切替。モーダルが右下縮小して背景透過、地図クロスヘアカーソル
- **逆引き**：地図クリック時に Nominatim `/reverse` で場所名取得
- ピックターゲット：訪問場所 / 宿泊所（Issue #7）

**ヒートマップ**：

- 右上の「ヒートマップ」ボタンで切替
- データソース：フィルタ適用後の全旅行の places を `[lat, lng]` に展開
- `radius: 35` / `blur: 25` / `minOpacity: 0.35`（少量データでも視認可）
- `tabibako_heatmap` に永続化

**fitBounds オートズーム**：

- 旅行選択時、その旅行の全 places（+ 宿泊所）が画面内に収まるよう調整
- 場所 1 件：`setView` + zoom 12
- 場所 2+ 件：`fitBounds` + padding 40
- 不正座標は `Number.isFinite` + 範囲チェックで除外

### 3.4 右パネル：旅行詳細

```
┌──────────────────┐
│  写真ビューア    │  ← 矢印切替・カウンター（N/M）・キーボード ←→ 対応
│  （IDB から読込）│
├──────────────────┤
│ USJと京都        │  ← タイトル
│ 2024-11-08〜10   │
│                  │
│ 訪問場所         │
│  ・USJ           │
│  ・清水寺        │
│ 宿泊所           │
│  ・ホテルXX      │
│ 訪問地域         │
│  ・大阪府        │
│  ・京都府        │
│ 移動手段（青）   │
│  [電車][バス]    │
│ 同行者（緑）     │
│  [田中さん]      │
│ タグ（紫）       │
│  [テーマパーク]  │
│ メモ             │
│  ...             │
├──────────────────┤

└──────────────────┘
```

**仕様**：

- 写真ビューア：選択中の旅行の `photos` を IDB から非同期ロード、`object-fit: contain`、矢印ボタン + キーボード ←→（モーダル中・input フォーカス中は無効）
- 写真 2 枚以上のとき：左右矢印 + カウンター（N/M）表示
- 空のプロパティはセクションごと非表示（情報量を絞る）
- 編集ボタン：旅行データをモーダルで再オープン、全フィールド初期化
- 削除ボタン：確認ダイアログ → IDB の写真も連動削除

## 4. 旅行データ定義

### 4.1 プロパティ一覧

| プロパティ | 型 | 必須 | 備考 |
|------------|------|------|------|
| 旅行名 | テキスト | ✓ | 自由記述（例：「春の京都旅」） |
| 日程 | 日付範囲 | ✓ | 開始日〜終了日。日帰りは同日を指定。HTML5 `<input type="date">` |
| 訪問場所 | オブジェクトリスト | - | 複数登録可。`{ name, lat, lng, region }`。Sprint 2 時点では必須だったが UX 柔軟性のため必須解除 |
| 訪問地域 | 文字列配列 | 自動 | 訪問場所の `region` から重複排除して集約。`trip.regions` |
| 宿泊所 | オブジェクト | - | `{ name, lat, lng }`。Issue #7 で地図ピン付きに拡張。空のときは `null` |
| 移動手段 | マルチセレクト型 | - | 移動手段専用の値プール。初期値：徒歩・自転車・車・電車・バス・飛行機・船 |
| 同行者 | マルチセレクト型 | - | 同行者専用の値プール。人物名・グループ名（例：田中さん・家族） |
| タグ | マルチセレクト型 | - | タグ専用の値プール。完全自由（例：青春18きっぷ・日帰り） |
| メモ | テキスト（長文） | - | `<textarea>` で改行可能 |
| 写真 | 参照配列 | - | `[{ id }]` 形式。本体は IndexedDB の `photos` ストア（`{ id, dataURL, createdAt }`） |
| ID | UUID | 自動 | `crypto.randomUUID()` |

**localStorage キー設計**：

| キー | 内容 |
|---|---|
| `tabibako_trips` | 旅行データ全件（JSON 配列） |
| `tabibako_transport_pool` | 移動手段の値プール |
| `tabibako_companions_pool` | 同行者の値プール |
| `tabibako_tags_pool` | タグの値プール |
| `tabibako_filter` | 絞り込み 3 セクションの選択状態 |
| `tabibako_sort` | ソート選択（newest / oldest / name） |
| `tabibako_heatmap` | ヒートマップ ON/OFF |
| `tabibako_period_filter` | 期間絞り込み（`{ start, end }`） |
| `tabibako_panel_widths` | 左右パネル幅（`{ left, right }`） |

### 4.2 マルチセレクト型プロパティの共通仕様

移動手段・同行者・タグの 3 プロパティはすべて以下の仕様に従う。値プールはプロパティごとに独立。

| 項目 | 仕様 |
|------|------|
| 入力方式 | **Notion 型ドロップダウン**：フィールドクリックで展開、チップ表示でトグル選択 |
| 新規値追加 | テキスト入力でフィルター、未存在なら末尾に「+ "xxx" を新規追加」表示 |
| 重複検知 | `trim()` + 完全一致（大小文字・全半角は区別） |
| 値の解除 | チップ右側 ×・候補再クリックで toggle・Backspace（空入力時に最後の値削除） |
| キーボード操作 | ↑↓ で候補移動・Enter で確定・Tab で次入力・Esc で閉じる |
| IME 対応 | `e.isComposing` チェック + `compositionend` で変換中の再描画事故を回避 |
| 値プール削除 | 候補ホバー時の × ボタン → 確認ダイアログ。保存済み旅行のチップには影響しない |
| カラー規約 | 移動手段＝青・同行者＝緑・タグ＝紫 |

### 4.3 訪問場所サブデータ

| 項目 | 型 | 備考 |
|------|------|------|
| 名称 | テキスト | 例：「清水寺」。Nominatim `display_name` をフル文字列で保存 |
| 緯度 | 数値 | 住所検索 or 地図クリックで取得 |
| 経度 | 数値 | 同上 |
| 地域 | テキスト | 都道府県名 or 国名。Nominatim `address` から自動抽出 |

### 4.4 写真サブデータ

| 項目 | 型 | 備考 |
|------|------|------|
| id | UUID | IDB 主キー。旅行データには `[{ id }]` 参照のみ |
| dataURL | 文字列 | IDB に保存。`createImageBitmap` + Canvas で 1600px / JPEG 0.80 にリサイズ済み |
| createdAt | timestamp | 添付時刻 |

**写真処理仕様**（Issue #1 で決定）：

- リサイズ最大長辺：1600px
- JPEG 品質：0.80
- EXIF 方向保持：`imageOrientation: 'from-image'` で自動反映
- 同時アップロード上限：10 枚 / 1 操作
- アップロード前プレビュー：あり（誤添付防止、× で個別削除）
- 全画面 lightbox：なし
- スワイプ：なし（デスクトップ前提）

### US-04 旅行の絞り込み

**期待される結果**
- 移動手段・同行者・タグそれぞれ独立して絞り込める（同カテゴリ OR、カテゴリ間 AND）
- 期間で絞り込める（重なり判定、Issue #11）
- ソート：日程新しい順・古い順・旅行名あいうえお順
- 絞り込み・ソート状態は localStorage で永続化

### US-05 旅行データの管理

**期待される結果**
- 編集ボタンから全項目編集可能
- 削除ボタン → 確認ダイアログ → 旅行データ + IDB 写真の連動削除
- マルチセレクトの値プールはホバー × で削除可（保存済み旅行のチップには影響なし）

### US-06 ヒートマップで傾向把握

**期待される結果**
- 右上ボタンでヒートマップ ON/OFF 切替
- データソース：フィルター済全旅行の places を集約
- ヒートマップ ON 時の旅行選択（Issue #12）：選択旅行の selected ピンのみ表示、fitBounds 発火、ヒートマップレイヤーは維持

### US-07（追加）パネル幅のカスタマイズ

**期待される結果**
- 左右パネル境界をドラッグで幅変更、ダブルクリックで初期値復帰
- キーボード操作：Tab フォーカス・矢印 10px・Shift+矢印 50px・Home/End/Enter/Space
- 変更は `tabibako_panel_widths` に永続化
- 最小幅制限：左 240 / 右 280 / 中央 320px

## 8. 実装上の重要な設計判断（実装前仕様書になかった事項）

詳細は [`SPRINT_LOG.md`](../../SPRINT_LOG.md) を参照。本セクションは新規追加。

### 8.1 アーキテクチャ

- **単一 `index.html` 構成**：YAGNI による意図的選択。Sprint 進行で肥大化したら分割検討
- **JS は `App` 名前空間 + IIFE**：グローバル汚染回避（Sprint 1 の `const map` 直定義から Sprint 2 でリファクタ）

### 8.2 デザイントークン

- 指示書原本のモックは外部デザイントークン前提のため、`:root` に自前で CSS 変数を定義
- パネル幅は指示書原本（左 256 / 右 260）から 1.5 倍に拡張（左 384 / 右 390）

### 8.3 写真ストレージ

- 30 旅行 × 5 枚規模で localStorage 上限を超えるため、IndexedDB に分離（Issue #1）
- 旅行データには `[{ id }]` 参照のみ、本体は IDB

### 8.4 マルチセレクト UI

- Notion 型ドロップダウン採用（Issue #2）。指示書ではセレクトボックス型だった
- 値プール削除機能を「将来対応」から前倒し実装（実装軽量・保存済データに影響なし）
- IME 変換中の再描画事故を `e.isComposing` + `compositionend` で回避

### 8.5 地図ピン仕様

- Sprint 3 時点：選択中の旅行のピンのみ表示
- Issue #5：未選択時にも全旅行ピンを default 青で表示、選択時は色分け（dim/selected）に変更
- Issue #12：ヒートマップ ON でも選択時は selected ピンを表示

### 8.6 訪問地域

- 仕様書原本では「訪問都道府県」だが、海外旅行も扱えるよう「訪問地域」（国内＝都道府県・海外＝国名）に拡張（Sprint 5）
- マイグレーション：旧 `prefecture` / `prefectures` を `region` / `regions` にリネーム

### 8.7 訪問場所必須の解除

- 仕様書原本では訪問場所が必須だったが、UX 柔軟性のため必須解除（Sprint 4）
- 「日程と名前だけ先に記録」のような使い方を許容

### 8.8 アクセシビリティ

- 旅行カード：`role="button"` `tabindex="0"` `aria-pressed`（Sprint 3 レビュー指摘）
- resize-handle：`role="separator"` `aria-orientation="vertical"` `aria-valuemin/max/now` + キーボード操作（Issue #3 / #10）
- 写真ビューア：キーボード ←→ 対応（入力中・モーダル中は無効）
- フィルターチップ：`aria-pressed` 同期（Sprint 5 レビュー指摘）

### 8.9 F-18 の据え置き

- ズーム連動のヒートマップ / ピン切替（仕様書原本のオプション機能）は手動トグルで十分との判断で据え置き
